## 页面：上传/新建任务

- 路由：`/upload`
- 布局：单列居中，最大宽度 `max-w-3xl` (768px)，内容区垂直居中偏上

### 核心组件

1. **页面标题区**
   - 标题："新建解析任务"（--text-2xl, --font-weight: 590）
   - 副标题："上传图片或 ZIP 压缩包，Docling 将自动 OCR 并提取表格数据"（--text-sm, --muted）

2. **上传区域**（Dropzone）
   - 大面积虚线边框区域（border: 2px dashed var(--border)）
   - 拖拽时：边框变 var(--accent)，背景 rgba(37,99,235,0.04)
   - 中央：Upload 图标（Lucide, 48px, --muted）+ "拖拽文件到此处或点击选择"
   - 支持格式提示："支持 JPG / PNG / WebP / TIFF / PDF / ZIP（单文件 ≤50MB）"
   - 点击触发文件选择器
   - 支持多文件选择

3. **文件队列**（上传后显示）
   - 列表布局，每行：文件图标 + 文件名 + 文件大小 + 状态 + 删除按钮
   - 状态：待上传（灰色圆点）/ 上传中（进度条）/ 成功（Check 图标）/ 失败（X 图标 + 重试）
   - 可拖拽排序（调整处理顺序）
   - 批量操作栏：全选 / 批量删除 / 清空

4. **解析选项**（折叠面板，默认展开）
   - OCR 引擎选择：下拉菜单（auto / tesseract / easyocr / rapidocr）
   - 输出格式：复选框组（Markdown / JSON / HTML）
   - 表格提取模式：单选（快速 / 精准）
   - LLM 增强：开关 + 模型选择下拉（配置后可用）
   - LLM 提示词：文本域（可选，"提取所有表格数据并结构化整理"）

5. **操作按钮区**
   - 主按钮："开始解析"（Primary, 带 Zap 图标）
   - 次按钮："保存为模板"（Secondary）

### 交互

- 拖拽文件进入 → 边框高亮 + 背景微变色（100ms）
- 文件上传中 → 行内进度条（0-100%，150ms 过渡）
- 上传完成 → 自动添加到文件队列
- 点击"开始解析" → 跳转到任务列表页，新任务置顶并高亮
- 文件格式不支持 → Toast 错误提示 "不支持的文件格式：.xxx"

### 响应式

- 桌面：单列居中，max-w-3xl
- 平板：单列，内边距 24px
- 手机：单列全宽，内边距 16px，上传区域高度适配

### 状态覆盖

- **Loading**：上传中显示进度条，解析中按钮显示 Spinner
- **Empty**：初始状态，上传区域居中显示
- **Error**：上传失败显示红色 X + 重试按钮，格式错误显示 Toast
- **Populated**：文件队列展示已上传文件列表
- **Edge**：单文件 >50MB 拒绝上传并提示，文件数 >50 提示分批上传
