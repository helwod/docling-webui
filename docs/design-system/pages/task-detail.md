## 页面：任务详情

- 路由：`/tasks/:id`
- 布局：分屏布局，左原图预览（40%）+ 右解析结果（60%），可拖拽调整比例

### 核心组件

1. **页面标题区**
   - 左侧：返回按钮（ArrowLeft 图标, Ghost）+ 文件名（--text-xl, --font-weight: 590）
   - 右侧：导出按钮（Primary, Download 图标 + "导出"）+ 更多操作（MoreVertical 图标）
   - 导出下拉：Markdown / JSON / HTML / ZIP 打包（含原图+解析结果）

2. **任务状态条**（处理中时显示）
   - 背景 var(--warn-bg) + 左侧 Spinner + "正在解析中... 已完成 3/5 页"
   - 进度条：var(--accent) 填充 + var(--surface-warm) 轨道
   - 失败时：var(--danger-bg) + Alert 图标 + "解析失败：[错误信息]" + 重试按钮

3. **分屏内容区**

   **左侧：原始图片预览**
   - 背景 var(--bg)（暗色衬底突显图片）
   - 多页时：顶部缩略图条（可横向滚动，选中页高亮 var(--accent) 边框）
   - 主预览区：图片可缩放（鼠标滚轮）、可拖拽平移
   - 底部：页码指示 "3 / 5" + 缩放控制按钮

   **右侧：解析结果**（Tab 切换）
   - Tab 1：**Markdown 预览**
     - 渲染后的 Markdown 内容（表格、标题、列表）
     - 表格区域：var(--surface) 背景 + 1px var(--border) + 等宽字体数字列
     - 可滚动，内边距 24px
   - Tab 2：**表格数据**
     - LLM 整理后的结构化表格
     - 可编辑单元格（双击进入编辑模式）
     - 表头固定（sticky），行 Hover 高亮
     - 底部："复制为 CSV" + "导出 Excel" 按钮
   - Tab 3：**原始 JSON**
     - 代码块展示，等宽字体 var(--font-mono)
     - 语法高亮（关键字/字符串/数字不同色）
     - 折叠/展开 JSON 节点
     - 右上角："复制" 按钮
   - Tab 4：**LLM 对话**（如配置了 LLM）
     - 聊天界面：用户消息右对齐 + AI 回复左对齐
     - 输入框底部固定："针对此文档提问..."
     - 历史对话可滚动

4. **元数据侧边栏**（可折叠，右侧抽屉）
   - 任务 ID、创建时间、处理时长
   - 文件信息：文件名、大小、格式、页数
   - OCR 引擎、输出格式
   - LLM 模型（如使用）
   - Token 消耗（如使用 LLM）

### 交互

- 拖拽分屏分隔条 → 调整左右比例（最小 30%，最大 70%）
- Tab 切换 → 150ms 淡入
- 表格单元格双击 → 进入编辑模式，Enter 保存，Esc 取消
- 点击缩略图 → 左侧主预览切换到对应页
- 导出 ZIP → 包含原始图片 + Markdown + JSON + 表格 CSV
- LLM 对话发送 → 显示打字机效果（逐字显示）

### 响应式

- 桌面（≥1024px）：左右分屏 40/60
- 平板（768-1024px）：上下排列，上图下结果
- 手机（<768px）：Tab 切换"原图"/"结果"，一次只看一个

### 状态覆盖

- **Loading**：解析中显示进度条 + 骨架屏占位
- **Empty**：任务刚创建未开始时 "任务排队中，请稍候"
- **Error**：解析失败显示错误详情 + 重试按钮 + 联系信息
- **Populated**：完整展示原图 + 解析结果 + 表格
- **Edge**：超大 JSON（>1MB）提示"内容过大，建议下载查看"；超长表格分页（每页 50 行）
